### `shoebox.settings`

[Source](https://github.com/coperyan/shoebox/blob/main/shoebox/settings.py)

Application settings.

```
Key goals:
- No import-time side effects (no filesystem reads/dir creation at import).
- Allow config path override via env var.
- Provide a cached settings accessor for the rest of the codebase.

Environment variables:
- SHOEBOX_CONFIG_PATH: path to app.yaml (defaults to configs/app.yaml)
```

#### `class OneDriveSettings(BaseModel)`

```
Card scans fetched from OneDrive (Microsoft Graph) when they are not on
local disk -- how the Cloud Run ``create-listings`` job started from the
iOS app reaches ``SCAN_0234.jpg``. All fields default, so an existing
config without an ``onedrive`` section still validates; ``enabled`` is
false until ``client_id`` and ``scans_folder`` are set. See docs/api.md.
```

**Fields**

```
client_id: str = ''
authority: str = 'https://login.microsoftonline.com/consumers'
scans_folder: str = ''
scopes: list[str] = Field(default_factory=lambda: ['Files.ReadWrite'])
listed_subfolder: str = 'Listed'
token_cache_path: str = 'configs/onedrive_token_cache.json'
token_cache_uri: str | None = None
```

#### `normalize_onedrive_folder(value: str) -> str`

```
A folder path under the OneDrive root, as typed in the iOS app:
``" /Pictures/Card Scans/ "`` -> ``"Pictures/Card Scans"``.

The job moves listed scans out of this folder, so it must stay a plain
relative path: ValueError for an empty path, ``.`` / ``..`` segments,
backslashes, control characters, or a character OneDrive rejects in a name
(``:`` would also end the ``root:/path:`` segment of a Graph URL).
```

#### `with_scans_folder(settings: Settings, folder: str) -> Settings`

```
A copy of ``settings`` reading scans from ``folder`` instead of
``onedrive.scans_folder`` (one app-requested run).
```

#### `get_settings(config_path: str | os.PathLike[str] | None=None) -> Settings`

```
Load and validate settings from YAML.

This function is cached (singleton-like) but *does not* create directories.
Call `ensure_runtime_dirs()` explicitly from entrypoints.
```

#### `ensure_runtime_dirs(config_path: str | os.PathLike[str] | None=None) -> None`

```
Create local directories referenced by settings.
```

### `shoebox.ui.helpers`

[Source](https://github.com/coperyan/shoebox/blob/main/shoebox/ui/helpers.py)

#### `handle_image_path(img: str) -> str`

```
Normalize an image reference.

- If the provided string is an existing path, return it.
- If it is a scan number (``"123"``, or ``"123.0"`` from Excel), build the
  expected path under scans_dir using the configured scan naming convention
  (``scan_prefix`` / ``scan_number_padding`` / ``scan_extension``).
- Otherwise (a path that does not exist here) return it unchanged.
```
