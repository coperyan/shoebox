# Shoebox

*Every card collector keeps a shoebox. This one runs an eBay store.*

Shoebox is a Python toolkit that runs the operational loop of an eBay
sports-card store: checklist and parallel metadata in BigQuery, bulk listing
creation through the eBay Sell APIs, card-scan handling in GCS, order and
traffic monitoring, lifecycle automation (relists, offers, ending out-of-stock
items), saved-search alerts, and a Slack layer for notifications, price
approvals and remote commands.

## Quick orientation

- **Install**: `pip install -e .` (Python ≥ 3.11), then create the config files
  from the templates in `configs/*.example` — see [Setup](/guides/setup).
- **Run something**: the console script is `shoebox` (equivalently
  `python -m shoebox.cli`). `shoebox --help` lists all commands.
- **Day-to-day flow**: build a listing queue in the Streamlit UI (`shoebox ui`),
  from Excel (`create-queue-excel`), or on your phone (the iOS app talking to
  `shoebox api`), then publish with `create-listings`. Monitoring pipelines
  (`sync-orders`, `sync-active-listings`, …) snapshot eBay state into BigQuery.
  Slack receives status notifications and hosts the price-approval flow.
